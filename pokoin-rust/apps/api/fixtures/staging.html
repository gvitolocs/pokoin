Oracle API

Pokoin Oracle API

This host serves JSON under /api/…. It does not serve the marketplace SPA (that is https://pokoin.com). Omitting /api returns {"error":"API route not found."}.

Useful checks

  • /livez - process is up
  • /readyz - postgres and redis (cdn is degraded; meili and valkey are retired)
  • /healthz - same as readyz
  • /api/__contract - React/JS client contract
  • /api/marketplace-suggest?q=pika - pokoin-web typeahead (Meili)
  • /api/marketplace-search-page?query=pika - search page BFF
  • /api/marketplace-expansion-page?slug=white-flare - set desk (expansion.cardCount is stored catalog size)
  • /api/marketplace-blueprint-price?blueprintId=274416 - read-only price lookup
