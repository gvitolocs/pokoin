2. CONSTRUCTOR CONTRACT (what the integrator must build)
--------------------------------------------------------------------------
The root API owns the listener. This crate only builds a router:

    use std::sync::Arc;
    use pokoin_external::{router, DomainState};

    let state = DomainState::new(
        firestore,   // Arc<dyn pokoin_external::firebase::FirestoreStore>
        verifier,    // Arc<dyn pokoin_external::firebase::TokenVerifier>
        db,          // pokoin_external::db::DbPools::from_env(pool_max).await?
        redis,       // Option<pokoin_external::redis::RedisCache>  (None = degraded single instance)
    );
    let app = router(state);          // axum::Router, paths already include /api/...

`DomainState` is public and Clone. It holds:
  firestore, verifier, db, redis,
  cardtrader: CardTraderClient,        // default ctor reads CARDTRADER_API_BASE_URL
  powertools:  PowerToolsClient,       // default ctor reads the Power Tools/Outseta bases
  recognition: RecognitionClient,      // SCAN_PRIMARY_URL / SCAN_FALLBACK_URL
  sync_jobs: Arc<SyncJobs>,            // native background reconcile guard
  r2_user_photos: Option<R2Client>,    // from_env("R2_USER_PHOTOS_BUCKET")
  config: Arc<DomainConfig>            // cron/game secrets + webhook base URL

Production wiring notes:
  * `verifier` = Arc::new(FirebaseJwksVerifier::new(FIREBASE_PROJECT_ID)); tests
    use StaticVerifier (accepts `Bearer test-<uid>`).
  * `firestore` = Arc::new(FirestoreRest::from_env()?) in production;
    MemoryFirestore for tests/no-Firestore degraded mode.
  * `DomainState::for_test()` gives a fully deterministic instance
    (MemoryFirestore + StaticVerifier + disconnected pools + no workers).

Env read at route time (all optional unless noted):
  FIREBASE_PROJECT_ID / FIREBASE_CLIENT_EMAIL / FIREBASE_PRIVATE_KEY (FirestoreRest)
  MARKETPLACE_DATABASE_URL, MARKETPLACE_WRITER_DATABASE_URL, *_DATABASE_URL
  CARDTRADER_TOKEN_ENCRYPTION_KEY (64 hex chars = 32 bytes; required to store/read
    any CardTrader or Power Tools secret — routes fail 500 without it)
  CARDTRADER_API_BASE_URL, CARDTRADER_WEBHOOK_BASE_URL
  CARDTRADER_DAILY_LISTINGS_SECRET | CARDTRADER_DAILY_REFRESH_SECRET | CRON_SECRET
  CARDTRADER_GAME_INGEST_SECRET
  SCAN_PRIMARY_URL (default http://127.0.0.1:18151),
  SCAN_FALLBACK_URL (default http://127.0.0.1:18150), SCAN_*_TIMEOUT_MS, SCAN_PRIMARY_COOLDOWN_MS
  CLOUDFLARE_ACCOUNT_ID, R2_ACCESS_KEY_ID, R2_SECRET_ACCESS_KEY,
  R2_USER_PHOTOS_BUCKET (+ optional R2_USER_PHOTOS_PUBLIC_URL), POKOIN_PUBLIC_ORIGIN

3. INTEGRATION STEPS (root worker)
--------------------------------------------------------------------------
1. Add "crates/external" to pokoin-rust/Cargo.toml [workspace].members.
2. In pokoin-rust/crates/external/Cargo.toml delete the local `[workspace]`,
   `[workspace.package]` (version/edition/license) lines; the crate then
   inherits the root workspace exactly like the other crates. (Those three
   fields exist only so the crate can be its own workspace root until then.)
3. Optionally repoint the crate's dependency versions at the root
   [workspace.dependencies] entries (they are currently absolute pins so the
   crate builds standalone; versions are compatible with the root list:
   axum 0.8, axum multipart, reqwest 0.12 multipart).
4. Build `DomainState` in apps/api and nest `router(state)` under the root
   router. Nothing else is required: all paths are absolute /api/... .
5. Do not add a second listener; this crate opens no sockets.
